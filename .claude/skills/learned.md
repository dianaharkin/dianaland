Runs automatically at the end of any fix worth remembering. She can also just ask
"what have I learned?" or "what was that thing about the pictures again?"

## Appending

After a fix, add **one entry**, newest at the top of `LEARNED.md`:

```
## [what she'd call it]
[One or two sentences, her language. What happened, and the pattern behind it.]
*Came up: [date] — [what she was doing at the time]*
```

Example:

```
## Pictures disappearing
If a picture file gets renamed, the page keeps looking for the old name and just shows
nothing. Nearly every vanished picture is this.
*Came up: 2026-09-04 — adding the new photo to the forest*
```

## When NOT to append

Most of the time. Only write an entry if it's a pattern she'll meet again. Skip:
- one-off causes that won't repeat
- anything already in the file — **update that entry instead of adding a second one**
- fixes where the cause was genuinely boring

A short file she's read beats a long one she hasn't. Fifteen good entries is a finished manual.

## Looking things up

When she asks what something was, read `LEARNED.md` and answer from it, in one or two lines.
If it isn't in there, say so and answer anyway — then append it, because she just proved
it was worth remembering.

## Every so often

When the file passes ten entries, tell her once:
> "That's ten things in your notes now — that file is basically your site's manual, and
> you wrote all of it by breaking things."

Say it once. Don't make it a running score.
