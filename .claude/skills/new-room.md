name: new-room
description: Add a memory pop-up behind a photo on the site.
---

Some photos open a pop-up with a memory in it. This adds one.

1. Ask which photo, and what the memory is. Let her talk — take it in her words.
2. Write the pop-up using the **existing** styling: 24px radius, pill buttons, violet
   halo, glowing title, layered shadows. Copy the markup from a room that already
   works rather than writing new CSS. It should look like it was always there.
3. Her words go in as she said them. Fix spelling; don't rewrite her sentences.
   If a memory needs shaping, that's the Claude project on her phone, not this repo.
4. Wire the photo so tapping it opens the room, and make sure it closes properly.
5. Show her a preview. Then stop.

**Ask before assuming a memory is for visitors.** Some of what she tells you is context
for you, not copy for the site. If it isn't obvious, ask which.
